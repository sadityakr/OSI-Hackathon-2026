# Catalog: open experimental Raman spectra of energy materials, polymers, pharma/forensic, minerals/planetary, and ML benchmark sets

Compiled 2026-10-21 for the OSI Hackathon (RamanLens). Scope: raw numeric experimental spectra (csv, txt, xlsx, h5, mat, spc, jdx, npy), not figure images. Nothing was downloaded. Companion to `catalog-graphene-tmd.md` and `catalog-magnets-general.md`.

## Read this first: what was and was not verified

- "Page checked" means the landing page or README was read in this session and the file names, sizes and licence in the row are copied from it. Anything else is marked UNVERIFIED.
- Zenodo record pages answered one at a time (parallel fetches get HTTP 429 style rate limits). The Zenodo REST API was not used.
- Blocked or unreadable from the sandbox, so the related rows are UNVERIFIED or partial: PubMed Central pages (captcha), Hugging Face dataset search, OSF pages (x7dpz, 7cqv4), Figshare article pages, TUprints and TUdatalib (Anubis bot wall), PDS directory listings, Rodare (HZDR) record 2448, CRAN RamanMP manual (robots), PyPI pages for raman-data and raman-bench. The ETH research-collection page showed 429 for its file list.
- RRUFF now redirects from rruff.info to www.rruff.net (HTTP 302). Both host names are given where relevant.
- Suitability scale (1 to 5) is relative to RamanLens, an agent that interprets Raman spectra of 2D materials and magnets with physics relations and literature: 5 = directly usable and on topic, 4 = clean labelled data that exercises the pipeline, 3 = useful as a generic reference or format test, 2 = marginal or theory only or hard to use, 1 = off topic, no raw data, or a false lead.
- Honest overall finding: for family (a) there is almost no openly deposited raw Raman for cathodes, anodes, catalysts or PV absorbers. Papers put them in the supporting information as plots. The two real hits are a Cambridge operando CSV bundle and a Dryad battery-interphase reference library. Minerals, microplastics and pharma reference libraries are much better supplied. For family (d), the large benchmark collections are real but mostly biomedical or bioprocess, with materials content dominated by MLROD and RRUFF.

```powershell
# Helper: download only if the output file does not exist yet
function Get-File($url, $out) {
    if (Test-Path $out) { Write-Host "skip (exists): $out"; return }
    $dir = Split-Path -Parent $out
    if ($dir -and -not (Test-Path $dir)) { New-Item -ItemType Directory -Force -Path $dir | Out-Null }
    Write-Host "get: $url"
    Invoke-WebRequest -Uri $url -OutFile $out -UserAgent "Mozilla/5.0" -MaximumRedirection 5
}

function Expand-Once($zip, $dest) {
    if (Test-Path $dest) { Write-Host "skip (extracted): $dest"; return }
    Expand-Archive -Path $zip -DestinationPath $dest
}

$root = "data\raw\spectra"
```
