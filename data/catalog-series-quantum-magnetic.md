# Catalog: open experimental Raman SERIES (temperature, pressure, polarization, field, strain, gating) for quantum and magnetic materials

Compiled 2026-10-21 for the OSI Hackathon (RamanLens). Scope: raw numeric experimental Raman spectra that come as series along a physical control parameter. Nothing was downloaded.

## Read this first: method, what was verified, what was not

- **What worked.** The DataCite REST API (api.datacite.org), queried through the fetch tool, indexes Zenodo, Figshare, Mendeley Data, Dryad, Harvard Dataverse, Materials Cloud, institutional repositories and national repositories in one place. It returns full per-DOI metadata (title, description, rights, sizes, related paper DOI). Almost every record below was found and read that way. This is the one search route that worked from the sandbox; the Zenodo, Figshare, Dryad, Materials Cloud APIs themselves are blocked (proxy 403) and several landing pages gave a permission wall or bot wall.
- **What "verified" means here.** "Metadata read" means the DataCite record was read. File names are listed only where the record text itself names them (NiPS3, CoPS3, Dryad moire, ScV6Sn6 Materials Cloud, Illinois, Bath, Zenodo 15048152). Where the file list was not visible, the cell says "names not seen" and the record is marked UNVERIFIED for contents. Raman content inside a zip was never inspected.
- **Pages that could not be read:** TUdatalib handles 4928 and 4929 (Anubis bot wall), Harvard Dataverse landing page, Hamburg FDR landing page, Dryad API, Zenodo 7086415 (rate limit), PubMed Central (reCAPTCHA). SciDB (scidb.cn) was only read through DataCite.
- **Licence flags that matter for a public MIT repo:** records marked CC BY-NC or CC BY-NC-ND (SciDB sets, DRUM ScV6Sn6, Unicamp, Rice) must stay in the gitignored `data/raw/` folder and be cited, not redistributed; "no derivatives" also argues against republishing digitized or reprocessed copies. CC0 and CC BY records are safe to redistribute with credit.
- **Duplicate DOIs.** Many Zenodo, Czech and Materials Cloud records come as a pair (concept DOI plus version DOI). Both are listed once as "A / B". The PowerShell block resolves the latest version.
- **Honest overall finding.** Open raw Raman series are scarce, but not absent, and the best ones are very recent (2025 and 2026). Almost nothing exists for the classic textbook systems (bulk TaS2, TiSe2, NbSe2 temperature series, YBCO, NiO two-magnon, MnF2, SrTiO3 and PbTiO3 soft modes, V2O3, NdNiO3, black phosphorus, GeS, Ga2O3, CrI3, MnPS3, Fe3GeTe2). The usable open series are: NiPS3 and CoPS3 (Zenodo), MnSi2Te4 (SciDB), 2M-WS2 (Dataverse), WSe2/WS2 moire (Dryad), CrSBr polarized and resonance Raman (Czech repository), ScV6Sn6 (DRUM), Bi-2212 anti-Stokes (Hamburg), SrIrO3 (KIT), FePS3 (Geneva, access to verify), several high-pressure sets (SciDB), and graphene gating and strain sets.

## Download commands (Windows PC, run from the repo root `osi-hackathon-2026`)

Files go to `data\raw\spectra\<material>\`. Zenodo file names are resolved through the Zenodo API at run time (the PC can reach it). Records without a stable direct file URL are written to `data\raw\spectra\MANUAL_DOWNLOADS.txt` with the landing page; set `$OpenManual = $true` to open them in the browser. Items marked UNVERIFIED use the standard endpoint pattern of the repository and may need the landing page instead.

```powershell
# ---- setup and helpers (define first) ----
$ErrorActionPreference = "Continue"
$ProgressPreference = "SilentlyContinue"
$OpenManual = $false          # set $true to open the manual landing pages in the browser
$root = "data\raw\spectra"
New-Item -ItemType Directory -Force $root | Out-Null
$manualFile = Join-Path $root "MANUAL_DOWNLOADS.txt"

function Get-File($url, $out) {
    if (Test-Path $out) { Write-Host "skip  $out"; return }
    New-Item -ItemType Directory -Force (Split-Path -Parent $out) | Out-Null
    Write-Host "get   $out"
    try { Invoke-WebRequest -Uri $url -OutFile $out -UseBasicParsing -TimeoutSec 900 }
    catch { Write-Warning "FAILED $url : $($_.Exception.Message)" }
}

function Expand-Zips($dir) {
    Get-ChildItem $dir -Filter *.zip -ErrorAction SilentlyContinue | ForEach-Object {
        $dest = Join-Path $dir $_.BaseName
        if (-not (Test-Path $dest)) { Expand-Archive $_.FullName -DestinationPath $dest -Force }
    }
}

function Get-ZenodoRecord($id, $dir) {     # resolves concept or version ids to the latest version
    New-Item -ItemType Directory -Force $dir | Out-Null
    try { $rec = Invoke-RestMethod "https://zenodo.org/api/records/$id/versions/latest" }
    catch { $rec = Invoke-RestMethod "https://zenodo.org/api/records/$id" }
    ("{0} | {1} | {2}" -f $rec.id, $rec.metadata.title, $rec.metadata.license.id) |
        Tee-Object -FilePath (Join-Path $dir "_record.txt") -Append | Write-Host
    foreach ($f in $rec.files) {
        $name = $f.key -replace '[\\/:*?"<>|]', '_'
        Get-File $f.links.self (Join-Path $dir $name)
    }
    Expand-Zips $dir
}

function Add-Manual($material, $url, $note) {
    New-Item -ItemType Directory -Force (Join-Path $root $material) | Out-Null
    "{0} | {1} | {2}" -f $material, $url, $note | Add-Content $manualFile
    Write-Host "manual: $material -> $url"
    if ($OpenManual) { Start-Process $url }
}
```
