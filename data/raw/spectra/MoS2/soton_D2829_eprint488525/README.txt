DATA & FILE OVERVIEW
--------------------

This dataset contains:

One excel file with 4 tabs, one tab for each graph. 
Tab one - figure 2: raman spectra measured across 4 points, with raman shift and intensity in columns. 
Tab two - figure 3: raman E2g, A1g and difference between these for 7 samples. 
Tab three - figure 6: raw data for PL spectra for 4 samples. 
Tab four - figure 7: normalised data of figure 6.
